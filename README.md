# blood 🧛

Calculate and interpret the **Glucose Ketone Index (GKI)** and related metabolic metrics from blood glucose and ketone measurements.

## Installation

```bash
cargo install --git https://github.com/Kijewski/blood
```

## Usage

```bash
# Calculate GKI (glucose in mg/dL, ketones in mmol/L - defaults)
blood gki 100 1.0

# With explicit units
blood gki 5.5 mmol/L 18 mg/dL
blood gki 100 mg/dL 1.0 mmol/L

# Interpret glucose (fasting, 2h post-meal, post-meal)
blood glucose 90
blood glucose 5.0 mmol/L

# Interpret ketones
blood ketone 1.0
blood ketone 18 mg/dL
```

### GKI Argument Formats

| Format | Example | Description |
|--------|---------|-------------|
| `<glucose> <ketones>` | `100 1.0` | Glucose in mg/dL, ketones in mmol/L (defaults) |
| `<glucose> <glucose_unit> <ketones>` | `5.5 mmol/L 1.0` | Glucose with unit, ketones in mmol/L |
| `<glucose> <ketones> <ketones_unit>` | `100 18 mg/dL` | Glucose in mg/dL, ketones with unit |
| `<glucose> <glucose_unit> <ketones> <ketones_unit>` | `5.5 mmol/L 18 mg/dL` | Both with explicit units |

Supported units: `mg/dL`, `mmol/L` (case-insensitive for the `L`)

## What is GKI?

The **Glucose Ketone Index (GKI)** is a metric for tracking metabolic health:

```text
GKI = Glucose / Ketones   [both values converted to mmol/L]
```

| GKI Range | Interpretation |
|-----------|----------------|
|     < 1.0 | Therapeutic ketosis (e.g., epilepsy management) |
| 1.0 – 3.0 | High ketosis |
| 3.0 – 6.0 | Moderate ketosis |
| 6.0 – 9.0 | Low ketosis |
|     > 9.0 | No ketosis |

Lower GKI indicates deeper ketosis.
The index was popularized by Dr. Thomas Seyfried for metabolic therapy research.
